# Horská túra – Krkonoše

Jednoduchá 3D hra v prohlížeči. Procházíš se jako turista v Krkonoších a v pohledu třetí osoby se snažíš dojít až na vrchol Sněžky.

## Hrát

[Hrát horskou túru](https://romanzdk.github.io/horska-tura/)

## Ovládání

- WASD / šipky = chůze
- Shift = běh
- Mezerník = skok
- myš (táhnout) = kamera
- kolečko = přiblížení
- na mobilu joystick vlevo + tlačítko skoku + tažení prstem pro kameru

## Technologie

Čisté HTML + Three.js z CDN. Bez buildu, hostováno na GitHub Pages.

## Spuštění lokálně

```sh
python3 -m http.server
```

Pak otevři <http://localhost:8000>.
